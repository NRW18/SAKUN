# สลับสกุล

เว็บแอปแปลงไฟล์ที่ทำงานในเบราว์เซอร์ทั้งหมด ไฟล์ไม่ถูกอัปโหลดไปที่ไหน

## ทำอะไรได้
- แปลงรูปเป็น JPG, PNG, WebP ทีละหลายไฟล์ ปรับคุณภาพและย่อขนาดได้
- รวมรูปและไฟล์ PDF เป็น PDF ไฟล์เดียว จัดลำดับได้
- บันทึกทุกไฟล์เป็น ZIP
- ติดตั้งลงหน้าจอหลักและใช้ออฟไลน์ได้ (หลังเปิดครั้งแรกตอนมีเน็ต)

## โครงไฟล์
- `index.html` หน้าแอปทั้งหมด (HTML, CSS, JavaScript)
- `sw.js` service worker เก็บไฟล์ไว้ใช้ออฟไลน์
- `manifest.webmanifest` ข้อมูลแอปสำหรับติดตั้ง
- `icons/` ไอคอนแอป
- `vendor/` ไลบรารี pdf-lib และ JSZip

## เอาขึ้นเว็บฟรีด้วย GitHub Pages
1. สร้าง repository แบบ Public
2. อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ (รวมโฟลเดอร์ `icons` และ `vendor`)
3. ไปที่ Settings > Pages เลือก branch `main` แล้วกด Save
4. เปิดลิงก์ที่ได้ใน Chrome บนมือถือ แล้วเลือกติดตั้งแอปหรือเพิ่มลงในหน้าจอหลัก

## ลองรันในเครื่อง
```
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000

## เวลาแก้โค้ด
แก้เลข `VERSION` ใน `sw.js` ทุกครั้ง ไม่อย่างนั้นเครื่องที่เคยเปิดแล้วจะยังเห็นของเก่า
